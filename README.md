## 🚀 Projetos em destaque

### 📊 Credit Score Classification
Comparação de modelos de classificação multiclasse (Regressão Logística, Random Forest, LightGBM) aplicados ao contexto bancário. Inclui limpeza de dados, análise exploratória, validação cruzada, otimização de hiperparâmetros, rastreamento de experimentos com **MLflow** e técnicas de **Explainable AI (XAI)** para prever a categoria de score de crédito de um cliente.

`Python` `Scikit-learn` `LightGBM` `MLflow` `XAI`
**[🔗 Ver repositório](https://github.com/simires/Credit-Score-Classification)**

### 💰 Dashboard de Análise de Salários na Área de Dados
Dashboard interativo desenvolvido com **Streamlit** e **Plotly** para análise de salários por senioridade, tipo de contrato e tamanho da empresa.

`Python` `Streamlit` `Plotly`
**[🔗 Ver repositório](https://github.com/simires/dashboard-salarios-dados)**

### 🚢 Análise e Predição de Sobreviventes do Titanic
Análise exploratória, tratamento de dados e comparação de modelos de classificação (KNN, Árvore de Decisão, Regressão Logística e Naive Bayes) usando validação cruzada e GridSearchCV.

`Python` `Scikit-learn` `EDA`
**[🔗 Ver repositório](https://github.com/simires/titanic-avanti-bootcamp-cdd)**
